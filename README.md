# diffusion-model-inpainting
A Generative AI project that implements image inpainting using diffusion models. The model reconstructs missing or masked regions while preserving the surrounding visual context, enabling high-quality image restoration and content editing.

## Features

- Diffusion-Based Image Inpainting
- Mask-Guided Image Generation
- Text-Guided Image Editing
- High-Quality Image Restoration
- Context-Aware Content Synthesis
- Latent Diffusion Pipeline
- Custom Mask Support
- Performance Evaluation

## Tech Stack

- Python
- PyTorch
- Hugging Face Diffusers
- Stable Diffusion
- OpenCV
- Pillow
- NumPy
- Matplotlib

## Applications

- Image Restoration
- Object Removal
- Photo Editing
- Damaged Image Reconstruction
- Background Replacement
- AI Content Generation
- Digital Art Creation
